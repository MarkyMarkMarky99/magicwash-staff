Wash queue card: tap for detail

Both phones are live. New left column: tag code big, weight under it. Tap a card to open its detail. Swipe a card sideways to see the Unload / Cancel panels still work. Tap a photo to see that it stays separate.

A — Expand in place

Tap a card: it grows to show the program. One open at a time.

B — Overlay

Tap a card: a bottom sheet opens. X or backdrop closes.

Trade-offs we noticed

  • A stays in context. No new layer and nothing to close, but a 4-step program adds roughly 260px, so the open card pushes the other baskets down and often off screen. The program frame also sits inside the card frame, two hard-shadow boxes in one.
  • B has room. Both photos, before/after weight and all three times fit without cramming the card, and the long program never moves the list. The cost: it hides the list, and every look needs a close tap. It would be a route-owned overlay (like ?photo=) so Back closes it.
  • A can only show what the card already knows. It has no room for both photos or the time stamps. If staff will want those from the list, B is the only variant that carries them.
  • Both give the whole card one more meaning. Tap now means detail, swipe means actions, photo tile means viewer. Neither shows a visible hint that the card is tappable (not asked for here); a first-time user may not find it.
  • The note is rare. Only the legacy row (third card) has one, so the note block exists only there. In the list it is cut off by the meta line, which is the only place detail is really missing today.
