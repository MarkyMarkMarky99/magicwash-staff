- Server: `JobTicketScanService.scan()` `server/modules/job-tickets/job-ticket-scan.service.ts`.
  - `:37-39` reads every ticket with `laundry_item_id = tag` — **no `order_id` filter**.
  - `:40` picks the **first** ticket whose department matches.
  - `:57-71` blocks if any same-tag ticket with lower `step_no` is not Completed — across all orders and including the same department.
- Routes: `server/modules/work-orders/job-ticket-provisioning.ts:60` — Washing is always step 1, so a Washing ticket can only be "blocked by Washing" if the tag has ≥2 Washing tickets with different `step_no`.

- Frontend also resolves the ticket by tag only: `DepartmentWorkPage.vue:162`.
