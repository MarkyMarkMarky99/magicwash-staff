# Monthly package invoices

The package bill helper opens the existing invoice create page as a CYCLE draft for the selected package and customer. It seeds a removable package fee line, an overage line when the balance is negative, and one line for each eligible order item with no CREDIT rate and an active DEFAULT price that has not already been invoiced. An order with legacy manual USAGE (reference source ORDER) on this package is fully covered: its items are omitted from cash lines and usage warnings, and the order and deducted credits appear as information on the draft. New per-order USAGE (reference source Orders) retains per-item billing. Staff can edit or remove draft lines. The form shows the allowance, credits used, carried-in credits, and transferred-out credits. The invoice schema has no attachment or detail field for persisting this usage summary, so the summary remains a form preview pending an owner decision on where to store it. Invoice source fields remain on cash item lines when the draft is submitted.

For each sourced line, the server confirms that the order item belongs to the stated order, the order belongs to the invoice customer, and no active ORDER or CYCLE invoice already contains that source item. VOID and CANCELLED invoices do not block a replacement. Both the order invoice form and monthly package draft send source keys for their order item lines. Source order, source item, and service type are written to existing InvoiceItems columns. Package fee and overage lines have no order item source. An overage line uses InvoiceItems.sku to identify its package for the subsequent credit counter adjustment.

The helper uses the selected package's own period. The existing package purchase flow issues a CYCLE invoice for the new package fee before it creates the package row. Staff must remove an already billed fee line when preparing another bill for that package. Combining a prepaid next-month fee with the previous package's overage and cash items is not represented by this single-package draft; the billing period and package association for that mixed invoice need an owner decision.

For orders covered by manual usage, staff add any cash-only items to the invoice by hand because the helper omits all items from those orders.
