# Order image — API contract

Module `order-images` (Phase 4). Source: [`docs/plans/orders-backend.md`](../../../plans/orders-backend.md).
Sheet: `OrderImages` (read + append).

The binary never reaches the API. The frontend uploads to Firebase Storage
(`src/api/storage.js` → `uploadRaw`) and this endpoint only records which URL belongs to which order.

## `GET /api/order-images` — list

Query
- `orderId` — string, **required** → missing is 422
- `keyword` — string, default `''` (no-op)
- `page` — int > 0, default 1
- `perPage` — int > 0, max 500, default 500
- `sortBy` — `createdAt`, default `createdAt`
- `sortOrder` — `asc` | `desc`, default `asc`

Response `200 { data: OrderImageResponse[], meta.pagination: { page, perPage } }`
- `orderImageId` — string
- `orderId` — string
- `customerId` — string | null
- `deliveryId` — string | null
- `imageType` — string | null (free string on read; 13 live spellings + blanks, returned verbatim)
- `imagePath` — string | null (Firebase URL on new rows, legacy relative path on old rows, verbatim)
- `notes` — string | null
- `quantity` — number | null (decimal weight in kg, not a count)
- `createdAt` — string | null (ISO-with-`Z` or `dd/MM/yyyy HH:mm:ss`, verbatim)
- `createdBy` — string | null

## `GET /api/order-images/:id` — detail

Path
- `id` — `OrderImages.id`

Response `200 { data: OrderImageResponse }` — same fields as list.

Errors: 400 blank id · 404 not found · 409 multiple rows.

## `POST /api/order-images` — create

Request
- `orderId` — string, required
- `customerId` — string, nullable, default `null`
- `imageType` — enum `BAG` | `WEIGHT` | `DOCUMENT` | `FORM` | `PICKUP` | `HANGERS` | `DELIVERED`, required
- `imagePath` — string, required, must start with `http://` or `https://` → otherwise 422
- `deliveryId` — string, optional, nullable, default `null`
- `notes` — string, nullable, default `null`
- `quantity` — number ≥ 0, nullable, default `null`
- `createdBy` — string, required
- not accepted: `orderImageId`, `createdAt`

Response `201 { data: OrderImageResponse }` — same fields as list.

Behaviour
- `orderImageId` is server-generated by `generateShortId()` (`server/shared/utils/id.ts`) — an
  8-character short id with **no prefix**, matching the format already used by the live
  `OrderImages.id` column
- `createdAt` is stamped by `audit.onAppend`
- `deliveryId` is written when supplied, otherwise left blank

## Not available

- `PATCH` / `DELETE` — 405; `writes.update` and `writes.delete` are `false`
