# Package credit staff actions

The package detail page keeps the existing activity list and transaction form. Selecting USAGE shows a server-generated per-item breakdown and the projected balance in that form. The customer order detail usage overlay shows the same breakdown for its selected package. A confirmation writes the computed usage. Other transaction types retain their existing controls; adjustment can name an original USAGE for a correction.

The monthly bill action opens the existing invoice create page with a package route context. The form remains editable and uses its existing line editor, totals preview, and create outcome states. The renewal action opens the existing package create form with the next month's dates and the same package code. Pending one-sided transfers appear on the old package detail page with a repair action.
